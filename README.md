# Project 2 — Personal Finance Tracker

A premium glassmorphic Personal Finance Tracker built with Spring Boot, Spring Security (JWT), Hibernate/JPA, and an interactive Chart.js frontend dashboard.

## 🚀 Core Features
- **Transaction Logs:** Log income/expenses with auto-categorization.
- **Budgeting Engine:** Category-wise monthly limits with near-breach visual warnings.
- **Investment Portfolio:** Track stocks, mutual funds, and fixed deposits.
- **Financial Health Score:** Metric scoring based on debt-to-income and savings ratios.
- **Debt & Bill Reminders:** Integrated alerts for EMI and credit card due dates.
- **Dynamic Charts:** Chart.js data visualization (candlestick logs, monthly spending category ratios).

## 🛠️ Tech Stack
- **Backend:** Java, Spring Boot, JPA/Hibernate, Spring Security (JWT)
- **Database:** PostgreSQL / H2 Database
- **Frontend:** Vanilla HTML5, CSS3 (variables, transitions, glassmorphic filters), JavaScript, Chart.js

## 🐳 Docker Deployment
Run the standalone container:
```bash
docker-compose up -d --build
```
