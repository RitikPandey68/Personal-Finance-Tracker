Architecture & Implementation Plan: FinTech Add-on Modules for Personal Finance Tracker
We will transform the existing Personal Finance Tracker into an advanced AI-Powered FinTech Platform by incrementally adding 5 independent, modular extensions on top of the existing Spring Boot backend and glassmorphic frontend UI.

🎯 Proposed Add-on Modules Overview

 └── Glassmorphic Dashboard & Chart.js

      ├── 🤖 1. AI Financial Chatbot (STEP 1)
      │      ├── ChatController & ChatService
      │      ├── FinancialContextService (Aggregates Tx, Budget, Debt, Bills)
      │      └── Domain Tools (ExpenseTool, BudgetTool, InvestmentTool, HealthTool)
      │
      ├── 📈 2. Investment Win/Loss Recovery Simulator (STEP 2)

⚠️ User Review Required
IMPORTANT

AI Provider Integration for Chatbot: The AI Financial Chatbot is designed with an AIService abstraction layer. By default, it will include a Local Intelligent Context Engine (rule-based NLP financial analyst that works 100% offline out-of-the-box using the user's live database context) and can seamlessly integrate with OpenAI / Gemini API keys via application.properties when provided.

NOTE

PAN Verification Provider: Since live NSDL/ITD PAN APIs require commercial API credentials (e.g. Sandbox.co / Cashfree), the PanVerificationService will operate with a Sandbox Verification Mock Engine that validates PAN format patterns ([A-Z]{5}[0-9]{4}[A-Z]{1}), simulates verification states, and securely updates the user profile.

🛠️ Proposed Changes
Component 1: 🤖 AI Financial Chatbot Module (Step 1)
[NEW] 
ChatController.java
Exposes POST /api/chat and GET /api/chat/history REST endpoints.
[NEW] 
ChatService.java
Manages conversation flow, processes user prompts, invokes context aggregators and domain tools.
[NEW] 
FinancialContextService.java
Aggregates user's live data (Transactions, Budget status, Investment value, Debts, Bills, and Health Score) to feed into chatbot prompt context.
[NEW] 
AIService.java
Generates natural language responses based on context data and user intents ("Where am I spending most?", "Can I afford X?", "Why is spending high?").
[NEW] 
ChatMessage.java
 & 
ChatMessageRepository.java
Database entity to persist user chat history.
[NEW] Tools (ExpenseTool.java, BudgetTool.java, InvestmentTool.java, FinancialHealthTool.java)
Domain-specific tools that execute calculations (e.g. highest category spend, budget margin remaining, health score breakdown).
Component 2: 📈 Investment Recovery Simulator (Step 2)
[NEW] 
RecoveryController.java
Exposes POST /api/recovery/calculate and GET /api/recovery/scenarios.
[NEW] 
RecoveryService.java
 & 
RecoveryCalculator.java
Calculates loss recovery percentage required ((Original - Current) / Current), projected recovery timeline based on monthly investment contributions and multi-scenario returns (e.g., Scenario A: 8%, Scenario B: 12%, Scenario C: 15%).
Component 3: 🧠 Risk & Recommendation Engine (Step 3)
[NEW] 
RecommendationController.java
Exposes endpoints for risk assessment quiz submission and portfolio recommendation generation.
[NEW] 
RiskProfilingService.java
Evaluates 7-10 financial risk questions (Age, Horizon, Emergency Fund, Income Stability, Loss Tolerance) to categorize user into CONSERVATIVE, MODERATE, or AGGRESSIVE.
[NEW] 
PortfolioAnalysisService.java
Analyzes current asset class breakdown (Equity, Debt, Gold, Cash) and generates macro asset allocation recommendations.
Component 4: 🔮 Future Financial Security & Wealth Forecast (Step 4)
[NEW] 
SecurityController.java
Exposes /api/security/score and /api/security/wealth-forecast.
[NEW] 
SecurityScoreService.java
Calculates separate Financial Security Score (Emergency Fund readiness, Insurance cover, Goal preparedness, Retirement readiness, Debt protection).
[NEW] 
WealthSimulatorService.java
Projects wealth growth up to year 2040 using income growth rate (e.g. 8%), inflation rate (e.g. 6%), and expected investment returns (e.g. 10%).
Component 5: 🪪 PAN & Income Verification Engine (Step 5)
[NEW] 
PanController.java
 & 
IncomeController.java
Endpoints for PAN submission & verification, and multi-source income management (Salary, Freelance, Investments, Other).
[NEW] 
PanVerificationService.java
Sandbox validation engine for PAN card verification with verification status tracking.
